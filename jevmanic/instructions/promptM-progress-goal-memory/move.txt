Willy is a miner in a platform game. The goal: Willy must collect all keys,
then go into the exit portal, and he must stay alive. The target is the key
that Willy goes to now, or the portal when no key is left. Select the move that
is the best for Willy now. `moves` gives each move that Willy can make now. The
code removed each move that kills Willy. If each move kills Willy, `moves` says
this. `progress` tells if a move gets Willy nearer to the target. When the
target is on a different floor, `progress` tells if the move gets Willy nearer
to the way up or the way down to that floor. `collects_key` tells that Willy gets a key with this move.
`completes_cavern` tells that Willy goes into the portal with this move and the
cavern is complete. `place` tells how frequently Willy was at the place where the move
ends. `tried_from_here` tells if Willy made this move from this place before.
