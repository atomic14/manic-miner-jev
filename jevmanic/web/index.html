jev plays Manic Miner

jev is a small decision model from TypeSafe. It does not write text: it gets a description of a situation and a question, and it selects one answer. On this page it plays Manic Miner (ZX Spectrum, 1983). Miner Willy must collect all keys in a cavern and then go into the exit portal, and he must stay alive.

How it works, and how to read this page
  1. The game stops before each move. The code reads the game and writes a description as text. jev gets no picture.
  2. The code tries each of the 6 moves in the emulator first. A move that kills Willy is not offered to jev.
  3. jev selects one move (walk left or right, jump left, right, or up, or wait). The game runs that move, and then stops again.
  4. Less frequently, jev selects the key that Willy goes to next. A yellow box in the game shows that key.
  5. The right side of the page shows each answer of jev with its probabilities, and the exact data that jev got.

1 · Watch a recorded run · free

A replay plays a game that jev played before. It makes no jev calls and needs no API key. Start here.

2 · Let jev play a new game · uses the jev API

A live run calls jev before each move. One run costs approximately $0.005. It needs TYPESAFE_API_KEY in the .env file. The run is recorded, and you can replay it later.

Settings (the defaults are the normal configuration)

"jev selects": jev makes each key decision. "Fixed order": you give the order as key letters (the field starts with the optimum order of the cavern), and jev makes only the move decisions.

On (normal): the key decision gets a text map of the cavern. Off: it gets facts about each key only.

The code always removes a move that kills Willy directly. This check also removes a move after which Willy cannot stay alive for this number of moves. A larger number is more help from the code.

"promptA" (normal): jev gets the goal, the meaning of each fact, and knowledge of the game, and it decides. "promptB" (for comparison): jev gets a list of rules that we wrote. The instructions are the only difference: jev gets the same facts. Each set is a folder of text files in jevmanic/instructions/.
